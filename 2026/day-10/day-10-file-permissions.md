## Commands used :

1. touch
2. echo
3. vim
4. cat
5. head
6. tail
7. chmod
8. mkdir
9. ls

I learned how to:

1. Create files using touch, echo, and vim

2. View file content using cat, head, and tail

3. Make scripts executable using chmod +x

4. Set secure permissions like:

444 - Read-only

640 - Owner full access, group read-only

755 - Executable directory access
