## OSI vs TCP/IP

1. L1 Physical – Cables, signals, hardware transmission
2. L2 Data Link – MAC address, switching
3. L3 Network – IP addressing & routing
4. L4 Transport – TCP/UDP, ports
5. L5 Session – Connection management
6. L6 Presentation – Encryption/formatting
7. L7 Application – User-facing protocols (HTTP, DNS)

## TCP/IP  (4 Layers)

1. Link – Physical + Data Link
2. Internet – IP routing
3. Transport – TCP/UDP
4. Application – HTTP, HTTPS, DNS, SSH

## Where Protocols Sit

1. IP → Internet Layer (OSI L3)
2. TCP/UDP → Transport Layer (OSI L4)
3. HTTP/HTTPS → Application Layer (OSI L7)
4. DNS → Application Layer (uses UDP/TCP 53)
